# Flux 1.3.0

## Новое

- **Правила роутинга теперь работают и в режиме TUN.** Раньше настройки
  "этот сайт — напрямую / заблокировать / через VPN" (в том числе по
  категориям вроде "реклама" или "страна") применялись только в режиме
  Proxy — в TUN весь трафик всё равно шёл через тоннель. Теперь правила
  соблюдаются в обоих режимах.
- **Базы для роутинга (geoip/geosite) обновляются сами**, без ожидания
  новой версии приложения. В настройках можно указать свою ссылку на базы
  или обновить их вручную кнопкой.
- **Резервные домены подписки.** Если сервис, у которого вы взяли
  подписку, вдруг сменит или потеряет домен, Flux сможет сам попробовать
  запасные адреса при следующем обновлении подписки — это должен настроить
  сам сервис, ничего делать вручную не нужно.
- **Автозапуск с Windows — гибче.** Можно выбрать: запускаться обычно или
  сразу с правами администратора (это нужно, если хотите, чтобы Flux сам
  подключался в режиме TUN при входе в систему — без прав TUN недоступен).
  Отдельно можно указать, показывать окно при автозапуске или сразу
  сворачиваться в трей.
- **Автоматическое подключение при запуске** — приложение может само
  подключиться к последнему выбранному серверу сразу после старта, без
  клика "Подключить".
- **Уведомления Windows.** При подключении, отключении и ошибках теперь
  показывается обычное системное уведомление (не только внутри окна
  приложения) — удобно, если окно свёрнуто в трей. Можно отключить в
  настройках.
- **Иконка в трее меняется** в зависимости от того, отключены вы, в Proxy
  или в TUN. В меню трея по правому клику теперь видно, к какому серверу
  вы подключены и в каком режиме.
- **Android: плитка в шторке быстрых настроек**, как у WireGuard — можно
  включить/выключить VPN одним тапом, не открывая приложение.

## Исправления

- Обфускация Salamander для Hysteria2-серверов раньше не работала на
  самом деле, хотя подключение проходило — теперь применяется как надо.
- Переключение на другой сервер или вариант подключения, пока VPN уже
  активен, раньше просто подсвечивало новый выбор в списке, но не
  переподключало — теперь реально переподключает.
- Выпадающий список в настройках (например, выбор автозапуска) иногда
  вылезал за край окна и обрезался — исправлено.
- Android: ссылки `flux://...` (например, для быстрого добавления
  подписки) теперь открываются так же, как на Windows.
